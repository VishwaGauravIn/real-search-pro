# RealSearchPro - Block Sponsored Search Results

A lightweight, security-focused Chrome Extension (Manifest V3) designed for corporate and developer environments to prevent **malvertising** and **search-ad phishing** on Google Search.

## About

Attackers frequently purchase sponsored search placements targeting developer tools and software queries (such as package managers, CLI tools, crypto wallets, or enterprise SaaS logins). These sponsored results appear above legitimate organic search results and mimic official websites to trick engineers or finance employees into installing malware or infostealers.

**RealSearchPro** eliminates this attack surface by automatically blocking and removing sponsored search results on Google Search before a user can see or click them.

## Features

- **Automatic Sponsored Result Protection**: Blocks top, bottom, and sidebar sponsored search placements on Google Search in real time.
- **Zero-Flash Protection**: Prevents sponsored links from briefly flashing on screen while search results load.
- **Protection Dashboard**: View blocked counts across Today, 7 Days, 30 Days, and All-Time, inspect your 7-Day activity chart, see top blocked advertiser domains (30-day rolling), or pause protection at any time from the extension popup.

## Installation (Developer Mode)

1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Enable **Developer mode** in the top-right corner.
3. Click **Load unpacked** and select this folder (`/Users/vishwagauravin/Development/WorkZone/extensions/block-sponsored-results`).
